// 01 · Básico

Variables

Una variable es un espacio con nombre en la memoria del computador que almacena un valor. En Python no se declara el tipo explícitamente; el intérprete lo infiere automáticamente al momento de la asignación. Son el bloque fundamental de cualquier programa: sin variables no hay datos, sin datos no hay programa.

Tipado dinámico

Python determina el tipo en tiempo de ejecución, no al declarar. Una misma variable puede cambiar de tipo durante la ejecución sin errores.

Asignación con =

No se necesitan palabras clave como var o int. Basta escribir nombre = valor para crear y asignar en una sola operación.

Nombres válidos

Deben empezar con letra o guión bajo _. No pueden comenzar con número ni contener espacios. Son sensibles a mayúsculas: Edad ≠ edad.

Asignación múltiple

Python permite asignar varias variables en una sola línea: a, b, c = 1, 2, 3 o dar el mismo valor: x = y = 0.

variables.py 
1# Declaración de variables


2nombre   = "Paula"       # str


3edad     = 17             # int


4promedio = 9.8           # float


5activo   = True          # bool


6


7# Asignación múltiple


8x, y, z = 1, 2, 3


9print(nombre, edad)      # Paula 17
!

Por convención Python usa snake_case para variables (nombre_completo). Las constantes se escriben en MAYÚSCULAS: PI = 3.14159.

Tipos de Datos

Los tipos de datos definen la clase de valor que puede guardar una variable y qué operaciones son posibles sobre ella. Python incluye tipos primitivos integrados. La función type() permite conocer el tipo de cualquier valor en tiempo de ejecución, y funciones como int(), str() o float() permiten convertir entre tipos.

int

Números enteros sin parte decimal: positivos, negativos o cero. Sin límite de tamaño en Python 3.

edad = 17  |  temp = -5  |  cero = 0

float

Números con parte decimal (punto flotante). Usado para cálculos científicos o valores con precisión decimal.

pi = 3.14159  |  peso = 52.5

str

Cadenas de texto entre comillas simples o dobles. Soportan concatenación, slicing e interpolación con f-strings.

nombre = "Paula"  |  ciudad = 'GDL'

bool

Solo dos valores: True o False. Son la base del control de flujo y las condiciones.

activo = True  |  error = False

NoneType

Representa la ausencia de valor con la palabra clave None. Equivale al nulo de otros lenguajes.

resultado = None

Conversión de tipos

Funciones integradas para cambiar de tipo: int(), float(), str(), bool(). Pueden generar error si el valor no es compatible.

int("42") → 42  |  str(17) → "17"

tipos.py 
1print(type(42))       # <class 'int'>


2print(type(3.14))     # <class 'float'>


3print(type("Hola"))   # <class 'str'>


4print(type(True))     # <class 'bool'>


5print(type(None))     # <class 'NoneType'>


6numero = int("100")    # "100" → 100


7texto  = str(3.14)    # 3.14 → "3.14"

// 03 · Básico

Operadores

Los operadores son símbolos especiales que indican al intérprete realizar una operación entre uno o más valores llamados operandos. Python cuenta con operadores aritméticos, de comparación, lógicos y de asignación. Son el mecanismo principal para calcular, comparar y decidir dentro de un programa.

Aritméticos

+ suma · - resta · * multiplicación · / división · % módulo (resto) · ** potencia · // división entera.

Comparación

== igual · != diferente · > mayor · < menor · >= mayor/igual · <= menor/igual. Siempre retornan True o False.

Lógicos

and (ambas verdaderas) · or (al menos una verdadera) · not (niega la condición). Trabajan sobre valores booleanos.

Asignación compuesta

+= · -= · *= · /= · **=. Combinan la operación con la asignación: a += 5 equivale a a = a + 5.

operadores.py 
1a, b = 10, 3


2print(a + b)      # 13


3print(a ** b)     # 1000  (potencia)


4print(a % b)      # 1     (módulo)


5print(a // b)     # 3     (división entera)


6print(a > b)      # True


7print(a == 10 and b < 5)  # True


8a += 5             # a ahora vale 15

// 04 · Control de Flujo

Condicionales

Las estructuras condicionales permiten que el programa tome decisiones: ejecutan un bloque de código si una condición es verdadera y otro bloque diferente si es falsa. En Python se usan if, elif y else. La indentación (4 espacios) delimita los bloques — no se usan llaves como en otros lenguajes.

if

Evalúa la condición. Si es True ejecuta el bloque indentado debajo. Si es False, lo salta por completo.

elif

"else if": evalúa una segunda condición si la anterior fue falsa. Se pueden encadenar múltiples elif consecutivos.

else

Se ejecuta cuando ninguna condición anterior fue verdadera. Es el caso por defecto y es opcional.

Indentación obligatoria

Python usa 4 espacios para delimitar bloques. Es sintaxis, no estilo. Un bloque mal indentado genera un IndentationError.

condicionales.py 
1nota = 8.5


2


3if nota >= 9:


4    print("Excelente")


5elif nota >= 7:


6    print("Aprobado")     # ← se ejecuta este


7else:


8    print("Reprobado")
"La indentación no es estilo en Python — es sintaxis. Un bloque mal indentado genera un error."

// 05 · Control de Flujo

Bucles

Los bucles permiten repetir un bloque de código múltiples veces sin escribirlo manualmente. Python ofrece dos tipos: for para iterar sobre una secuencia y while para repetir mientras se cumpla una condición. Son la base de la automatización y el procesamiento de colecciones de datos.

for

Itera sobre los elementos de cualquier secuencia: lista, cadena, rango, tupla, diccionario. Ideal cuando se conoce el número de repeticiones.

while

Repite el bloque mientras la condición sea True. Útil cuando el número de iteraciones no se conoce de antemano.

range()

Genera una secuencia de números. range(5) → 0 a 4. range(1,10,2) → 1,3,5,7,9. Muy usada con for.

break / continue

break termina el bucle inmediatamente. continue salta a la siguiente iteración sin ejecutar el resto del bloque actual.

bucles.py 
1# Bucle for con range


2for i in range(1, 4):


3    print(f"Vuelta {i}")


4# Vuelta 1 / Vuelta 2 / Vuelta 3


5


6# Bucle while


7contador = 0


8while contador < 3:


9    contador += 1


10print(contador)   # 3

Funciones

Una función es un bloque de código reutilizable con un nombre que realiza una tarea específica. Se define una vez con def y se puede llamar tantas veces como sea necesario. Recibe datos de entrada llamados parámetros y devuelve un resultado con return. Son la herramienta principal para organizar y reutilizar código de forma modular.

def

Palabra clave para definir una función. Seguida del nombre, paréntesis con parámetros opcionales y dos puntos. El cuerpo va indentado.

Parámetros y argumentos

Los parámetros son variables en la definición. Los argumentos son los valores reales pasados al llamar la función.

return

Devuelve un valor al punto donde se llamó la función y termina su ejecución. Sin return, la función retorna None automáticamente.

Valores por defecto

Los parámetros pueden tener valores predefinidos: def f(x, y=10). Si no se pasa y, se usa 10 automáticamente.

Scope (alcance)

Las variables creadas dentro de una función son locales: solo existen dentro de ella y no afectan el código exterior.

Lambda

Funciones anónimas de una sola expresión: doble = lambda x: x * 2. Útiles para operaciones simples en línea o como argumentos.

funciones.py 
1def saludar(nombre, saludo="Hola"):


2    return f"{saludo}, {nombre}!"


3


4print(saludar("Paula"))          # Hola, Paula!


5print(saludar("Mundo", "Hey"))   # Hey, Mundo!


6


7# Lambda


8doble = lambda x: x * 2


9print(doble(7))                   # 14

Listas y Tuplas

Las listas y tuplas son colecciones ordenadas que almacenan múltiples elementos en una sola variable. La diferencia clave: las listas son mutables (se pueden modificar) y las tuplas son inmutables (no cambian tras su creación), siendo más eficientes y seguras para almacenar datos fijos como coordenadas o configuraciones.

Lista [ ]

Se define con corchetes. Puede contener cualquier tipo de dato mezclado. Sus elementos se pueden agregar, eliminar o modificar libremente.

Tupla ( )

Se define con paréntesis. Una vez creada no se puede modificar. Ideal para datos constantes como coordenadas o configuraciones fijas.

Indexación

Acceso por posición desde 0. Los índices negativos van desde el final: lista[-1] es siempre el último elemento.

Slicing

Extrae porciones: lista[1:4] devuelve del índice 1 al 3. Con paso: [::2] toma uno de cada dos elementos.

Métodos de lista

.append() agrega al final · .remove() elimina por valor · .sort() ordena · .pop() quita el último.

len()

Función integrada que devuelve el número de elementos de cualquier colección: len([1,2,3]) → 3.

listas.py 
1frutas = ["manzana", "pera", "uva"]


2frutas.append("mango")


3print(frutas[0])      # manzana


4print(frutas[-1])     # mango


5print(frutas[1:3])    # ['pera', 'uva']


6


7# Tupla inmutable


8punto = (10, 20)


9print(punto[1])        # 20

Diccionarios

Un diccionario es una colección de pares clave: valor. Cada clave es única y sirve para acceder directamente a su valor, como un diccionario real donde la palabra es la clave y su definición el valor. Son extremadamente eficientes para buscar, organizar y estructurar datos con nombres descriptivos en lugar de índices numéricos.

Sintaxis { }

Se define con llaves. Cada par: "clave": valor, separados por comas. Las claves son generalmente cadenas o números.

Acceso a valores

dict["clave"] accede directamente. dict.get("clave") es más seguro: devuelve None si la clave no existe en lugar de error.

Mutabilidad

Los diccionarios son mutables. Se pueden agregar, modificar o eliminar pares en cualquier momento tras su creación.

Métodos clave

.keys() lista claves · .values() lista valores · .items() retorna pares · .pop("k") elimina una clave.

diccionarios.py 
1alumna = {


2    "nombre"  : "Paula",


3    "semestre": 2,


4    "promedio": 9.8


5}


6print(alumna["nombre"])      # Paula


7alumna["grupo"] = "IA"       # Agregar nueva clave


8for k, v in alumna.items():


9    print(k, ":", v)

Clases y POO

La Programación Orientada a Objetos (POO) organiza el código en torno a objetos que combinan datos (atributos) y comportamientos (métodos). Una clase es el molde que define la estructura; un objeto es una instancia concreta creada a partir de ella. Permite modelar el mundo real de forma natural, organizada y reutilizable.

class

Palabra clave para definir una clase. Por convención se usa CamelCase: class MiClase:. Es el plano de los objetos.

__init__

Constructor: se ejecuta automáticamente al crear un objeto. Inicializa los atributos de la nueva instancia con los valores recibidos.

self

Referencia al objeto actual. Primer parámetro de todos los métodos. Permite acceder y modificar los atributos propios del objeto.

Herencia

Una clase puede heredar atributos y métodos de otra clase padre. Promueve la reutilización y extensión del comportamiento sin repetir código.

Encapsulamiento

Agrupa datos y métodos en una unidad. Atributos con _ son protegidos y con __ son privados, restringiendo el acceso externo.

Polimorfismo

Distintos objetos pueden responder al mismo método de formas diferentes. Permite código más flexible, genérico y escalable.

clases.py 
1class Alumna:


2    def __init__(self, nombre, promedio):


3        self.nombre   = nombre


4        self.promedio = promedio


5


6    def presentar(self):


7        return f"Soy {self.nombre}, promedio {self.promedio}"


8


9paula = Alumna("Paula", 9.8)


10print(paula.presentar())  # Soy Paula, promedio 9.8
"Las clases son los planos; los objetos son los edificios construidos a partir de esos planos."

Módulos y Librerías

Un módulo es un archivo Python (.py) con funciones, clases o variables reutilizables. Una librería es una colección de módulos agrupados. Python incluye una extensa biblioteca estándar y permite instalar miles de paquetes externos con el gestor pip, ampliando enormemente las capacidades del lenguaje sin tener que programar todo desde cero.

import

Importa un módulo completo. Se accede a sus elementos con notación de punto: math.sqrt(16).

from … import

Importa elementos específicos directamente: from math import pi. No se necesita el prefijo del módulo al usarlo.

as (alias)

Asigna un nombre corto al módulo: import numpy as np. Convención estándar para librerías populares como numpy y pandas.

Biblioteca estándar

Incluida con Python sin instalar nada: math · random · datetime · os · json · sys · re.

pip

Gestor de paquetes de Python. Instala librerías externas desde la terminal: pip install nombre. Lista instaladas: pip list.

Librerías populares

numpy · pandas · matplotlib · requests · flask · scikit-learn · pillow · pygame.

modulos.py 
1import math


2from random import randint


3import datetime as dt


4


5print(math.sqrt(144))        # 12.0


6print(math.pi)                # 3.14159...


7print(randint(1, 10))        # número aleatorio 1-10


8print(dt.date.today())        # fecha actual

Tip: Instala librerías externas con pip install nombre en la terminal. Para proyectos profesionales usa entornos virtuales (python -m venv env) para mantener las dependencias aisladas por proyecto y evitar conflictos entre versiones.
