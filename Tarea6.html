✦ Concepto Básico

Variables

Una variable es un espacio en memoria donde se almacena un valor que puede cambiar durante la ejecución de un programa. En Python, las variables no necesitan ser declaradas con un tipo específico; el intérprete infiere el tipo automáticamente al momento de asignar el valor.

Tipado dinámico

Python determina el tipo de dato en tiempo de ejecución, no al declarar la variable. Esto permite flexibilidad y rapidez al programar.

Asignación simple

Se asigna con el símbolo =. No se requiere palabra clave especial como var o int.

Nombres válidos

Deben empezar con letra o guión bajo, no pueden comenzar con número ni contener espacios. Son sensibles a mayúsculas.

Reasignación libre

Una variable puede cambiar de tipo de dato en cualquier momento simplemente asignándole un nuevo valor.

▸ Ejemplo de código

# Declaración de variables en Python nombre = "Paula" # Cadena de texto edad = 17 # Entero promedio = 9.8 # Decimal (float) activo = True # Booleano print(nombre, edad) # Paula 17

✦ Estructura Fundamental

Tipos de Datos

Los tipos de datos definen qué clase de valor puede guardar una variable y qué operaciones se pueden realizar con ella. Python incluye tipos primitivos integrados listos para usar sin importar librerías adicionales.

int

Números enteros sin decimales. Pueden ser positivos, negativos o cero. Ejemplo: 42, -10.

float

Números con parte decimal. Útiles en cálculos matemáticos y científicos. Ejemplo: 3.14, -0.5.

str

Cadenas de texto. Se delimitan con comillas simples o dobles. Admiten operaciones como concatenación y slicing.

bool

Valores lógicos: True o False. Son la base de las condiciones y el flujo de control del programa.

NoneType

Representa la ausencia de valor. Se usa con la palabra clave None, equivalente a "nulo".

type()

Función integrada para conocer el tipo de dato de cualquier variable en tiempo de ejecución.

▸ Ejemplo de código

print(type(42)) # <class 'int'> print(type(3.14)) # <class 'float'> print(type("Hola")) # <class 'str'> print(type(True)) # <class 'bool'> print(type(None)) # <class 'NoneType'>

✦ Operaciones

Operadores

Los operadores son símbolos especiales que indican al intérprete que realice una operación matemática, lógica o de comparación entre uno o más valores (operandos). Son la base del cálculo y la toma de decisiones en cualquier programa.

Aritméticos

+ suma, - resta, * multiplicación, / división, % módulo, ** potencia, // división entera.

Comparación

== igual, != diferente, > mayor, < menor, >= mayor o igual, <= menor o igual. Devuelven booleano.

Lógicos

and (ambas condiciones verdaderas), or (al menos una verdadera), not (niega la condición).

Asignación

=, +=, -=, *=. Permiten modificar el valor de una variable combinando operación y asignación en un solo paso.

▸ Ejemplo de código

a, b = 10, 3 print(a + b) # 13 print(a ** b) # 1000 print(a % b) # 1 print(a > b) # True print(a == 10 and b < 5) # True

✦ Flujo de Control

Condicionales

Las estructuras condicionales permiten que un programa tome decisiones y ejecute bloques de código distintos dependiendo de si una condición es verdadera o falsa. En Python se usan las palabras clave if, elif y else.

if

Evalúa una condición. Si es True, ejecuta el bloque de código indentado. Si es False, lo omite completamente.

elif

Abreviatura de "else if". Permite evaluar una segunda condición si la primera fue falsa. Se pueden encadenar múltiples elif.

else

Bloque que se ejecuta cuando ninguna de las condiciones anteriores fue verdadera. Actúa como caso por defecto.

Indentación

Python usa espacios (4 recomendados) para delimitar los bloques. Es obligatorio y reemplaza el uso de llaves {} de otros lenguajes.

▸ Ejemplo de código

nota = 8.5 if nota >= 9: print("Excelente") elif nota >= 7: print("Aprobado") # ← se ejecuta este else: print("Reprobado")

✦ Iteración

Bucles

Los bucles permiten repetir un bloque de código múltiples veces sin tener que escribirlo manualmente. Python ofrece dos tipos: for para iterar sobre una secuencia y while para repetir mientras se cumpla una condición.

for

Itera sobre los elementos de una secuencia (lista, cadena, rango, etc.). Ideal cuando se conoce el número de repeticiones.

while

Repite el bloque mientras la condición sea verdadera. Útil cuando no se sabe de antemano cuántas iteraciones se necesitan.

range()

Función que genera una secuencia de números. range(5) produce 0, 1, 2, 3, 4. Muy usada con for.

break / continue

break termina el bucle inmediatamente. continue salta a la siguiente iteración sin ejecutar el resto del bloque.

▸ Ejemplo de código

# Bucle for con range for i in range(1, 4): print(f"Vuelta {i}") # Vuelta 1 / Vuelta 2 / Vuelta 3 # Bucle while contador = 0 while contador < 3: contador += 1 print(contador) # 3

✦ Reutilización de Código

Funciones

Una función es un bloque de código reutilizable que realiza una tarea específica. Se define una vez y puede ejecutarse (llamarse) tantas veces como se necesite, recibiendo datos de entrada (parámetros) y devolviendo un resultado (valor de retorno).

def

Palabra clave para definir una función. Seguida del nombre, paréntesis con parámetros opcionales y dos puntos.

Parámetros

Variables que recibe la función al ser llamada. Pueden tener valores por defecto y ser opcionales.

return

Devuelve un valor al punto donde se llamó la función. Sin return, la función retorna None.

Alcance (scope)

Las variables creadas dentro de una función son locales: solo existen dentro de ella y no afectan el código exterior.

▸ Ejemplo de código

def saludar(nombre, saludo="Hola"): return f"{saludo}, {nombre}!" print(saludar("Paula")) # Hola, Paula! print(saludar("Mundo", "Hey")) # Hey, Mundo!

✦ Colecciones

Listas y Tuplas

Las listas y tuplas son estructuras de datos que almacenan colecciones ordenadas de elementos. Las listas son mutables (se pueden modificar), mientras que las tuplas son inmutables (no cambian después de crearse), lo que las hace más seguras y eficientes para datos fijos.

Lista [ ]

Se define con corchetes. Puede contener cualquier tipo de dato. Sus elementos se pueden agregar, eliminar o cambiar.

Tupla ( )

Se define con paréntesis. Una vez creada, no se puede modificar. Ideal para datos constantes como coordenadas.

Indexación

Se accede a los elementos por su posición, empezando en 0. Los índices negativos acceden desde el final: -1 es el último.

Métodos útiles

.append() agrega, .remove() elimina, .sort() ordena, len() devuelve la longitud de la colección.

▸ Ejemplo de código

frutas = ["manzana", "pera", "uva"] frutas.append("mango") print(frutas[0]) # manzana print(frutas[-1]) # mango punto = (10, 20) # Tupla inmutable print(punto[1]) # 20

✦ Colecciones Clave-Valor

Diccionarios

Un diccionario es una colección no ordenada de pares clave-valor. Cada elemento tiene una clave única que sirve para acceder a su valor, similar a un diccionario real donde la palabra es la clave y su definición es el valor. Son muy eficientes para buscar datos.

Sintaxis { }

Se define con llaves. Cada par se escribe como clave: valor separado por comas. Las claves suelen ser cadenas.

Acceso

Se accede al valor usando la clave entre corchetes: dict["clave"] o con el método .get("clave") para evitar errores.

Mutabilidad

Los diccionarios son mutables. Se pueden agregar, modificar o eliminar pares en cualquier momento tras su creación.

Métodos útiles

.keys() lista las claves, .values() lista los valores, .items() retorna pares para iterar fácilmente.

▸ Ejemplo de código

alumna = { "nombre": "Paula", "semestre": 2, "promedio": 9.8 } print(alumna["nombre"]) # Paula alumna["grupo"] = "IA" # Agregar clave for k, v in alumna.items(): print(k, ":", v)

✦ Programación Orientada a Objetos

Clases y POO

La Programación Orientada a Objetos (POO) organiza el código en torno a objetos que combinan datos (atributos) y comportamientos (métodos). Una clase es el molde o plantilla; un objeto es la instancia concreta creada a partir de esa plantilla.

class

Palabra clave para definir una clase. Por convención, los nombres de clases se escriben en CamelCase (primera letra mayúscula).

__init__

Método constructor que se ejecuta automáticamente al crear un objeto. Inicializa los atributos de la instancia.

self

Referencia al objeto actual. Se pasa como primer parámetro en todos los métodos para acceder a los atributos propios.

Herencia

Una clase puede heredar atributos y métodos de otra. Fomenta la reutilización de código y la extensión del comportamiento.

▸ Ejemplo de código

class Alumna: def __init__(self, nombre, promedio): self.nombre = nombre self.promedio = promedio def presentar(self): return f"Soy {self.nombre}, promedio {self.promedio}" paula = Alumna("Paula", 9.8) print(paula.presentar()) # Soy Paula, promedio 9.8

✦ Extensión del Lenguaje

Módulos y Librerías

Un módulo es un archivo Python que contiene funciones, clases o variables reutilizables. Una librería es un conjunto de módulos agrupados. Python incluye una extensa biblioteca estándar y permite instalar miles de paquetes externos con pip.

import

Importa un módulo completo. Se accede a sus elementos usando la notación de punto: módulo.función().

from … import

Importa elementos específicos de un módulo directamente al espacio de nombres, sin necesitar el prefijo del módulo.

Librería estándar

Módulos incluidos con Python: math, random, datetime, os, json. No requieren instalación.

pip

Gestor de paquetes de Python. Permite instalar librerías externas como numpy, pandas, requests desde la terminal.

▸ Ejemplo de código

import math from random import randint print(math.sqrt(144)) # 12.0 print(math.pi) # 3.14159... print(randint(1, 10)) # número aleatorio del 1 al 10
